# Дорожная карта AegisROM

Краткая версия для пользователей — в разделе «Планы» в [README.ru.md](../README.ru.md) ([English](../README.md)). Здесь подробности. Планы могут меняться.

## 0.5.5 – 0.5.7

### Названия ромов по хешу (DAT No-Intro / Redump) — в `dev`
- Сверка по CRC32 + размеру и SHA1 с DAT No-Intro (картриджи) и Redump (диски), для PBP и образов больше 1 ГБ — по серийнику.
- Найденное название — основной источник при онлайн-переименовании, остальное ищется в Libretro по имени. Источник виден в карточке и журнале.
- Ограничения: CHD и другие сжатые форматы по хешу не сверяются. См. [docs/dat.md](dat.md).

### Патчер русификаторов и ромхаков
- Форматы патчей: IPS, BPS, UPS, xdelta.
- Выбираешь чистый ром (USA/EUR) и файл патча, программа патчит ром и ставит тег `(RUS)` или `[Hack]`.
- Результат кладётся в библиотеку или в сборку. Хранение — см. «Хаки и пропатченные ромы» ниже.

### Хаки и пропатченные ромы
Связан с патчером: патчер создаёт такие ромы, этот пункт отвечает за то, как их хранить, распознавать и не терять.

**Структура папок.** В папке каждой консоли две подпапки:

```text
<консоль>/
├── hackroms/   # хаки и пропатченные ромы: сюда они перемещаются, здесь хранятся и обрабатываются
└── patch/      # файлы патчей (.ips / .bps / .ups / .xdelta) для оригинальных, непропатченных ромов
```

**Анализ при сканировании.**
- Определять, что ром — хак или пропатченная версия, а не дубль оригинала.
- В карточке рома показывать, чем он отличается от оригинала: какой оригинал, что за патч (перевод, хак, фикс), автор и версия, если их можно определить.

**1G1R.** Хак или пропатченный ром не удаляется как дубль. Вместо этого программа предлагает перенести его в `hackroms/`.

**Статус «пропатчен» / «хак».**
- Фильтры и сортировка библиотеки по статусу.
- Сборки по статусу (например, «только русификаторы» или «без хаков»).
- Переименование с учётом статуса: тег статуса в конструкторе имён файлов.

### Проверка BIOS и прошивок
- Сверка папки `bios/` по MD5 / CRC32 с зелёным или красным статусом для PS1, PS2, Sega CD, Dreamcast, GBA, NDS, Arcade.
- Автоматическое копирование нужных BIOS на флешку при выгрузке сборки.

### Быстрый тест игры в окне
- Кнопка «Быстрый тест» в карточке игры: запуск через WebAssembly-ядро для 8/16/32-битных систем.
- Нужна, чтобы за пару секунд проверить язык рома, русификатор или рабочий ли образ перед добавлением в сборку.

## 0.5.8 — мастер первоначальной настройки

**Статус / status:** первая версия в `dev`, см. [setup-wizard.md](setup-wizard.md). First version is in `dev`.

Открывается при первом запуске. Использует уже готовые инструменты (сканирование, 1G1R, переименование, раскладка по папкам), поэтому идёт отдельным минорным обновлением после патчера и проверки BIOS.

### Шаги мастера
1. **Язык интерфейса.**
2. **Тип установки:** «Клиент» или «Клиент + сервер». Вариант с сервером пока скрыт и появится в релизе, когда будет готова серверная часть.
3. **Где хранить файл библиотеки.**
4. **Где хранить ромы** (папка мастер-библиотеки).
5. **Путь к своим ромам** для импорта. Можно пропустить.
6. **Как переименовывать ромы:** шаблон из конструктора имён. Можно пропустить, тогда имена не меняются.

### После мастера
- В фоне по шагам запускаются сканирование, копирование, перемещение и переименование. Из этого собирается библиотека. Прогресс каждого шага виден в окне.
- Пока задачи идут, открывается тур по приложению: подсказки по основным функциям, как ими пользоваться, и кнопки перехода в нужный раздел.

## До 0.6.0 — нативное окно и macOS

Подробный план по этапам и выбор технологии — в [docs/desktop-shell.md](desktop-shell.md).

### Своё окно вместо Edge / Chrome
- Окно на Wails v3 с системным WebView: WebView2 на Windows, WKWebView на macOS, WebKitGTK на Linux. Edge и Chrome больше не нужны.
- Настройки и базы библиотек хранятся на диске, а не в профиле браузера, и переносятся из старой версии сами.
- Доступ к папкам через программу по путям, без повторных разрешений браузера после перезапуска.

### Версия для macOS
- Один `.dmg` для Intel и Apple Silicon.
- Без подписи Apple: при первом запуске нужно разрешить приложение в «Конфиденциальность и безопасность». Инструкция будет в README.
- Запуск игр через эмуляторы для Mac: RetroArch, DuckStation, PCSX2, Dolphin, PPSSPP, mGBA и другие `.app`. OpenEmu — только открытие игры в его библиотеке.

### PortMaster через WSL на Windows
- Вместо режима `--classic-win32`: виртуальная среда Linux (WSL) с нативным PortMaster, как на приставках.
- Сначала прототип: большинство портов собраны под ARM64, на обычном ПК их, возможно, придётся запускать через эмуляцию.
