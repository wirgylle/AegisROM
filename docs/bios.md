# BIOS и прошивки / BIOS and firmware

## RU

Раздел **Среда → BIOS** объясняет новичку, что такое BIOS, какой консоли он нужен и куда его класть, и проверяет папку BIOS пользователя.

**Как устроено**
- `src/data/bios/libretroSystemDat.ts` — хеши (размер, CRC32, MD5) из libretro-database `dat/System.dat`, генерируется скриптом `node scripts/gen-bios-db.mjs [путь к System.dat]`. Данные под лицензией CC BY-SA 4.0, источник указан в файле и в интерфейсе.
- `src/data/bios/biosGuide.ts` — справочник: 25 систем, уровень нужности (обязателен / рекомендуется / необязателен / не нужен), группы файлов (`any` — хватит одного, `all` — нужны все, `anyFromSystem` — имя не важно, как у PS2), эмуляторы и куда класть, ссылки. Объяснение «зачем» на 9 языках.
- `src/utils/biosCheck.ts` — чистая логика сверки. Статусы файла: `ok`, `wrongPlace` (не та подпапка), `wrongName` (верный дамп под другим именем), `otherBios` (по имени совпал, но это другой BIOS), `unknownVersion` (хеша нет в базе), `missing`.
- `src/utils/biosScan.ts` — обход папки через File System Access API (глубина 4, файлы до 64 МБ), настоящий MD5 (`src/utils/md5.ts`) и CRC32, исправление имён копированием, копирование в сборку, `getVerifiedBiosFiles()` для других модулей (быстрый тест).
- Выгрузка сборки: строка «BIOS для сборки» показывает статус BIOS консолей в очереди; галочка «Скопировать BIOS» кладёт проверенные файлы в `bios/` (R36S/ArkOS, DuckStation), `BIOS/` (Miyoo/Anbernic), `Emulation/bios/` (EmuDeck). Для флеш-картриджей и PSP не копирует.

**Где взять.** AegisROM не скачивает и не раздаёт BIOS и не ссылается на сайты, которые их раздают. В карточках только: гайды по дампу со своей консоли, официальная прошивка PS3 с сайта Sony, свободные замены (OpenBIOS, встроенные HLE) и документация эмуляторов.

**Тесты:** `npm test` (MD5 по RFC 1321, логика статусов, полнота переводов).

## EN

The **Environment → BIOS** section tells newcomers what a BIOS is, which console needs one and where it goes, and checks the user's BIOS folder.

**How it works**
- `src/data/bios/libretroSystemDat.ts`: hashes (size, CRC32, MD5) from libretro-database `dat/System.dat`, generated by `node scripts/gen-bios-db.mjs [path to System.dat]`. The data is CC BY-SA 4.0; the source is credited in the file and in the UI.
- `src/data/bios/biosGuide.ts`: the guide. 25 systems, need level (required / recommended / optional / not needed), file groups (`any`: one is enough, `all`: all needed, `anyFromSystem`: any name, like PS2), emulators with where to put files, links. The "why" text is in 9 languages.
- `src/utils/biosCheck.ts`: pure matching logic. File statuses: `ok`, `wrongPlace`, `wrongName`, `otherBios`, `unknownVersion`, `missing`.
- `src/utils/biosScan.ts`: folder walk via the File System Access API (depth 4, files up to 64 MB), real MD5 (`src/utils/md5.ts`) and CRC32, name fixes by copying, copying into builds, `getVerifiedBiosFiles()` for other modules (quick test).
- Build export: the "BIOS for this build" strip shows the BIOS status of queued consoles; the "Copy BIOS" checkbox puts verified files into `bios/` (R36S/ArkOS, DuckStation), `BIOS/` (Miyoo/Anbernic), `Emulation/bios/` (EmuDeck). Nothing is copied for flash carts and PSP.

**Where to get BIOS files.** AegisROM never downloads or shares BIOS files and never links to sites that share them. Cards only link to guides for dumping your own console, the official PS3 firmware from Sony, free replacements (OpenBIOS, built-in HLE) and emulator docs.

**Tests:** `npm test` (MD5 RFC 1321 vectors, status logic, translation completeness).
