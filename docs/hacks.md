# Хаки, переводы и патчи

AegisROM отличает хаки, фанатские переводы и пропатченные ромы от оригиналов: не удаляет их как дубли, показывает, чем они отличаются, и умеет сам накладывать патчи.

## Папки

В папке каждой консоли есть две подпапки:

```text
snes/
├── hackroms/   # хаки, переводы и пропатченные ромы
└── patch/      # файлы патчей (.ips .ups .bps .xdelta) для оригинальных ромов
```

Папки создаются сами, когда программа впервые кладёт туда файл. Можно создать их и вручную.

## Как программа понимает, что ром — хак

По порядку надёжности:

1. **Патч из `patch/`.** Патчи BPS и UPS хранят контрольную сумму исходного рома и результата. Если ром получается этим патчем, в карточке будет написано «сделан патчем …». А у чистого рома, к которому подходит патч, — «в patch/ есть подходящие патчи».
2. **Сверка по хешу с DAT** (при онлайн-переименовании, см. [dat.md](dat.md)). Если хеш совпал с чистым оригиналом, ром считается оригиналом, даже если в имени стоит тег хака. Если хеша в DAT нет, а тег есть, в карточке будет «хеша нет в DAT: ром изменён».
3. **Теги в имени файла** (как в GoodTools и No-Intro):

   | Тег | Что значит |
   |---|---|
   | `[T+Rus]`, `[T+Rus1.0_Автор]`, `[T-Eng]`, `(Rus Translation)` | перевод; язык, версия и автор берутся из тега |
   | `[h]`, `[h1]`, `[hM04]`, `(Hack)`, `(Kaizo Hack)`, `[Hack]` | хак |
   | `[f]`, `[f1]`, `(Fixed)` | фикс (исправленный дамп) |
   | `[t]`, `[t1]`, `(Trainer)` | трейнер (встроенные читы) |
   | `(Patched)` | пропатченный ром |

4. **Папка `hackroms/`.** Ром без тегов, который лежит в `hackroms/`, считается пропатченным.

В карточке игры, в строке «Хак / патч», видно: что это (перевод, хак, фикс), язык, версия, автор, какой оригинал и каким патчем сделано.

## 1G1R

1G1R больше не убирает хаки и переводы как дубли оригинала. Точные копии (тот же CRC32) по-прежнему считаются дублями.

Если после 1G1R нашлись хаки не в `hackroms/`, откроется окно «Перенести хаки в hackroms/?». Отметьте нужные и нажмите «Перенести». Обложки, видео и сохранения переезжают вместе с ромом. «Оставить как есть» ничего не трогает.

При сортировке каталога хаки и переводы сразу раскладываются в `<консоль>/hackroms/`.

## Фильтры, сортировка, сборки

- **Библиотека → Статус:** все, только оригиналы, все изменённые, переводы, хаки, прочие патчи.
- **Сортировка → По статусу:** сначала оригиналы, потом переводы, хаки и прочие патчи.
- **Сборки → По статусу:** готовые подборки «Только русификаторы», «Только ромхаки» и «Только оригиналы, без хаков и патчей».

## Переименование

В конструкторе имён есть блок **«Статус (хак / перевод)»**. Он добавляет тег `[T+Rus]`, `[Hack]`, `[Fixed]`, `[Trainer]` или `[Patched]`. У оригиналов тег пустой, поэтому блок включён по умолчанию: без него переименованный хак получил бы имя оригинала.

Пример: `Final Fantasy (U) [T+Rus1.0_Shedevr].nes` → `Final Fantasy (USA) [T+Rus].nes`.

## Патчер

**Инструменты → Патчер ромов.**

1. Выберите чистый ром и файл патча. Программа покажет формат патча и проверит, подходит ли ром (для BPS и UPS — по CRC32).
2. Выберите тег: перевод (`T+Rus`, язык можно поменять), хак, фикс или свой.
3. **Пропатчить и скачать** — сохранить результат файлом. **Пропатчить в папку консоли…** — выбрать папку консоли: результат ляжет в `hackroms/`, а патч скопируется в `patch/`.

Если у SNES-рома есть 512-байтный копирный заголовок, а патч сделан для рома без него, программа уберёт заголовок сама.

### Форматы и ограничения

| Формат | Поддержка |
|---|---|
| IPS (включая RLE и усечение) | да |
| UPS | да, с проверкой CRC32 |
| BPS | да, с проверкой CRC32 и метаданными |
| xdelta (VCDIFF) | только без вторичного сжатия. Патчи, сделанные `xdelta3` с настройками по умолчанию, обычно сжаты: такой патч программа не наложит и скажет об этом. Пересоздать патч можно командой `xdelta3 -e -S none -s оригинал результат патч.xdelta`. Поддержка сжатых патчей запланирована. |

- Ром — до 512 МБ, весь читается в память.
- Связь ромов с патчами из `patch/` идёт по CRC32 первых 16 МБ рома, поэтому для ромов больше 16 МБ она не сработает.
- IPS и xdelta не хранят контрольную сумму рома: проверить, подходит ли ром, заранее нельзя.
