## AegisROM 0.5.4 (beta)

Первый публичный релиз на GitHub.

### Что скачать
- `AegisROM-Setup-v0.5.4-Win11-x64.exe` — установщик, рекомендуется.
- `AegisROM-Portable-Win11-x64.exe` — портативная версия без установки.
- `AegisROM-v0.5.4-Win11-x64.zip` — всё сразу одним архивом.
- `aegis-scanner-win11-x64.exe` — консольный сканер для продвинутых пользователей.

Нужна Windows 11 x64. Файлы пока не подписаны: если SmartScreen предупредит, нажмите «Подробнее» → «Выполнить в любом случае».

### Что нового
- Программа стала заметно легче: в exe больше не вшиты прошлые версии.
- Защита локального API: другие сайты и программы не могут управлять AegisROM через браузер.
- Новый вид окна: фиксированные панели и аккуратная вёрстка на разной ширине окна.
- Ссылки на скачивание в программе ведут на эту страницу Releases.

### Beta
Эти функции есть, но ещё в разработке и могут работать не всегда:
- каталог PortMaster и проверка портов на ПК;
- запуск игры в эмуляторе из карточки.

### Известные проблемы
- Переименование находит правильное название не для всех ромов.

Ошибки и идеи пишите в [Issues](https://github.com/wirgylle/AegisROM/issues).
