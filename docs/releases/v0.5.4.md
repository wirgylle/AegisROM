## AegisROM 0.5.4 (beta)

Первый публичный релиз на GitHub.
First public release on GitHub.

### Что скачать / Downloads
- `AegisROM-Setup-v0.5.4-Win11-x64.exe`: установщик, рекомендуется / installer, recommended.
- `AegisROM-Portable-Win11-x64.exe`: портативная версия без установки / portable, no install.
- `AegisROM-v0.5.4-Win11-x64.zip`: всё одним архивом / everything in one archive.
- `aegis-scanner-win11-x64.exe`: консольный сканер / command-line scanner.

Нужна Windows 11 x64. Файлы пока не подписаны: если SmartScreen предупредит, нажмите «Подробнее» → «Выполнить в любом случае».
Requires Windows 11 x64. Files aren't signed yet: if SmartScreen warns, click "More info" → "Run anyway".

### Что нового / What's new
- Программа стала заметно легче: в exe больше не вшиты прошлые версии. / Much smaller exe: old builds are no longer embedded.
- Защита локального API: другие сайты и программы не могут управлять AegisROM через браузер. / Local API protection: other sites and apps can't control AegisROM through the browser.
- Новый вид окна: фиксированные панели и аккуратная вёрстка на разной ширине. / New layout: fixed panels that adapt to window width.
- 1G1R: дубли переносятся в `_Duplicates_1G1R`, а не удаляются. / 1G1R moves duplicates to `_Duplicates_1G1R` instead of deleting them.
- Переименование: убран `(World)`, источник названия виден в журнале и карточке. / Renaming drops `(World)` and shows where each name came from.
- Доступ к папкам сохраняется между запусками. / Folder access persists between launches.
- Исправлены окна в Edge, правая панель показывает контекст текущего раздела. / Fixed windows in Edge; the right panel follows the current section.
- Ссылки на скачивание в программе ведут на страницу Releases. / Download links in the app point to Releases.

### Beta
Эти функции есть, но ещё в разработке / These work but are still in development:
- каталог PortMaster и проверка портов на ПК / PortMaster catalog and PC port check;
- запуск игры в эмуляторе из карточки / launching a game in an emulator from its card.

### Известные проблемы / Known issues
- Переименование находит правильное название не для всех ромов. / Renaming doesn't find the right name for every ROM.

Ошибки и идеи / Bugs and ideas: [Issues](https://github.com/wirgylle/AegisROM/issues).
