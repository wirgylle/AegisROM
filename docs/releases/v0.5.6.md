## AegisROM 0.5.6 (beta)

### Что скачать / Downloads
- `AegisROM-Setup-v0.5.6-Win11-x64.exe`: установщик, рекомендуется / installer, recommended.
- `AegisROM-Portable-Win11-x64.exe`: портативная версия без установки / portable, no install.
- `AegisROM-v0.5.6-Win11-x64.zip`: всё одним архивом / everything in one archive.
- `aegis-scanner-win11-x64.exe`: консольный сканер / command-line scanner.

Нужна Windows 11 x64. Файлы пока не подписаны: если SmartScreen предупредит, нажмите «Подробнее» → «Выполнить в любом случае».
Requires Windows 11 x64. Files aren't signed yet: if SmartScreen warns, click "More info" → "Run anyway".

### Что нового / What's new
- **Запуск игры в окне программы**: встроенный эмулятор (EmulatorJS) запускает игру прямо из карточки, без установки эмуляторов. BIOS берётся из раздела BIOS, поддерживаются Sega CD и PC Engine CD. / **Play in the app window**: the built-in emulator (EmulatorJS) runs a game from its card with no emulator installed. BIOS comes from the BIOS section; Sega CD and PC Engine CD are supported.
- **Раздел «Среда → BIOS»**: справочник для новичков, проверка файлов по MD5 и копирование BIOS в сборку. / **Environment → BIOS**: a beginner guide, MD5 check and copying BIOS into builds.
- **Хаки и патчи**: папки `hackroms/` и `patch/` в папке консоли, распознавание хаков и переводов, патчер IPS/UPS/BPS/xdelta. 1G1R не удаляет хаки как дубли, а предлагает перенести их в `hackroms/`. / **Hacks and patches**: `hackroms/` and `patch/` folders per console, hack and translation detection, an IPS/UPS/BPS/xdelta patcher. 1G1R offers to move hacks to `hackroms/` instead of removing them as duplicates.
- **Мастер первой настройки** и тур по основным разделам. / **First-run setup wizard** and a tour of the main sections.
- **Коллекции в Библиотеке**: одна игра на разных консолях в одной группе, описание игры из Wikidata. / **Library collections**: one game across consoles in one group, game description from Wikidata.
- **Онлайн-переименование и скраппер**: DAT из libretro-database, скраппер больше не удаляет рабочие обложки и видео. / **Online rename and scraper**: libretro-database DATs; the scraper no longer removes working box art and videos.
- **Окно «Посмотреть сборку»**: что войдёт в сборку, с поиском. / **View build window**: what goes into a build, with search.
- Настройки хранятся на диске, а не только в браузере. / Settings are stored on disk, not only in the browser.
- Нативное окно (Wails) в виде опции: запуск с флагом `--native-window`. / Optional native window (Wails): start with `--native-window`.
- README на русском и английском. / README in Russian and English.

### Beta
Эти функции есть, но ещё в разработке / These work but are still in development:
- нативное окно `--native-window` / the `--native-window` native window;
- запуск во встроенном эмуляторе: не все консоли и форматы / play in the built-in emulator: not every console and format;
- каталог PortMaster и проверка портов на ПК / PortMaster catalog and PC port check.

### Известные проблемы / Known issues
- В режиме «Редактор» галочки ставятся, но ручной правки названия, данных и путей к медиа пока нет. / In Editor view the checkboxes work, but manual editing of names, details and media paths isn't there yet.
- Переименование находит правильное название не для всех ромов (например, `FFVIII` не становится `Final Fantasy VIII`). / Renaming doesn't find the right name for every ROM (e.g. `FFVIII` doesn't become `Final Fantasy VIII`).

Ошибки и идеи / Bugs and ideas: [Issues](https://github.com/wirgylle/AegisROM/issues).
