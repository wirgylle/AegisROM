## AegisROM 0.6.0 (beta)

### Что скачать / Downloads
- `AegisROM-Setup-v0.6.0-Win11-x64.exe`: установщик для Windows, рекомендуется / Windows installer, recommended.
- `AegisROM-Portable-Win11-x64.exe`: портативная версия без установки / portable, no install.
- `AegisROM-v0.6.0-Win11-x64.zip`: всё одним архивом / everything in one archive.
- `aegis-scanner-win11-x64.exe`: консольный сканер / command-line scanner.
- `AegisROM-v0.6.0-macOS-universal.dmg`: **macOS** `beta`, один файл для Intel и Apple Silicon, macOS 11+ / one file for Intel and Apple Silicon, macOS 11+.

Windows: файлы пока не подписаны. Если SmartScreen предупредит, нажмите «Подробнее» → «Выполнить в любом случае».
Windows: files aren't signed yet. If SmartScreen warns, click "More info" → "Run anyway".

macOS: приложение не подписано Apple, поэтому первый запуск будет заблокирован. Как открыть: [docs/macos.md](https://github.com/wirgylle/AegisROM/blob/main/docs/macos.md).
macOS: the app isn't signed by Apple, so the first start is blocked. How to open it: [docs/macos.md](https://github.com/wirgylle/AegisROM/blob/main/docs/macos.md).

### Что нового / What's new
- **Сохранения рядом с ромом**: игра из встроенного «Запуска» сохраняется файлами `.srm` / `.state` рядом с ромом, с историей последних 10 версий и откатом. Блок «Сохранения» в карточке игры показывает и сохранения из папок эмуляторов. При переименовании, переносе и удалении дубля 1G1R сохранения едут за ромом. При выгрузке сборки в папку или на SD сохранения едут вместе с ней, а более новые с карты возвращаются в библиотеку. / **Saves next to the ROM**: games from the built-in Play save as `.srm` / `.state` files next to the ROM, with a history of the last 10 versions and restore. The Saves block in the game card also shows saves from emulator folders. Saves follow the ROM on rename, move and 1G1R duplicate removal. Exporting a build to a folder or SD takes the saves along and brings newer ones from the card back.
- **Заливка сборки по Wi-Fi** (SFTP и SMB): без извлечения карты, едут только новые и изменённые файлы, прерванная заливка докачивается. Профили для ArkOS, muOS, Knulli, Batocera, Onion, TrimUI и Steam Deck, пароли в системном хранилище паролей. / **Upload a build over Wi-Fi** (SFTP and SMB): no need to take the card out, only new and changed files are sent, an interrupted upload resumes. Profiles for ArkOS, muOS, Knulli, Batocera, Onion, TrimUI and Steam Deck; passwords are kept in the system password store.
- **Версия для macOS** `beta`: AegisROM.app в одном `.dmg` для Intel и Apple Silicon, запуск игр через эмуляторы для Mac. / **macOS version** `beta`: AegisROM.app in one `.dmg` for Intel and Apple Silicon, games launched through Mac emulators.
- **Свои коллекции и серии**: группировка вручную, предложения после скана, группировка и сортировка по студии. / **Your own collections and series**: group by hand, suggestions after a scan, group and sort by studio.
- **Серии в библиотеке**: вся линейка игры одной группой; многодисковые игры и сокращения вроде `FFVIII` переименовываются правильно. / **Series in the library**: a whole game franchise as one group; multi-disc games and short names like `FFVIII` are renamed correctly.
- **Рабочий режим «Редактор»**: ручная правка названия, данных и путей к медиа, массовая правка. / **Working Editor view**: manual editing of names, details and media paths, bulk editing.
- **Данные игр в CSV / XML**: выгрузка, правка в таблице и загрузка обратно с предпросмотром; читается `gamelist.xml` от ES, ES-DE и Skraper. / **Game data in CSV / XML**: export, edit in a spreadsheet and load back with a preview; `gamelist.xml` from ES, ES-DE and Skraper is read too.
- **Скраппер**: выбор источников и их порядка (Libretro, ScreenScraper, готовая папка Skraper / ES-DE / Batocera / RetroBat), переход к следующему источнику при промахе, выбор типов медиа, отчёт о причинах промахов. Больше нет фейкового прогресса после перезапуска. / **Scraper**: choose sources and their order (Libretro, ScreenScraper, a ready Skraper / ES-DE / Batocera / RetroBat folder), fall back to the next source on a miss, choose media types, a report of why games were missed. No more fake progress after a restart.
- **Операции без полного скана** и окно выбора области для 1G1R, переименования и скраппера. / **Operations without a full scan** and a scope window for 1G1R, rename and the scraper.
- **Библиотека**: выбор картинки на карточках, фильтр «только коллекции / серии / без одиночек». / **Library**: choose the picture on cards, "only collections / series / no single games" filter.
- **Быстрая выгрузка сборки** с медиа и `gamelist.xml` под ваше устройство. / **Fast build export** with media and `gamelist.xml` for your device.
- **Окно «Настройки»** и тема как в системе. / **Settings window** and a theme that follows the system.
- **Переименование**: названия-числа (`1942`), точки (`E.T.`), повтор `(USA)(USA)`. / **Rename**: numeric titles (`1942`), dots (`E.T.`), repeated `(USA)(USA)`.
- Кнопка ☕ «Угостить разработчика кофе»: донат в USDT с QR-кодом. / ☕ "Buy the developer a coffee" button: USDT donation with a QR code.

### Известные проблемы / Known issues
- **macOS на настоящем Mac не проверялась.** Сборка проходит в CI, но запуск, окно, эмуляторы и Связка ключей не проверены. Если не запускается, напишите в Issues, какая у вас версия macOS и что видите. / **macOS hasn't been checked on a real Mac.** It builds in CI, but start-up, the window, emulators and Keychain are unverified. If it doesn't start, open an Issue with your macOS version and what you see.
- **Заливка по Wi-Fi на настоящих приставках не проверялась**: проверена только на тестовых серверах SFTP и SMB. Логины и папки в профилях взяты из документации прошивок. / **Wi-Fi upload hasn't been checked on real handhelds**: only against test SFTP and SMB servers. Logins and folders in the profiles come from firmware docs.
- **Сохранения по Wi-Fi не синхронизируются**: со сборкой они едут только при выгрузке в папку или на SD. WebDAV пока нет. / **Saves don't sync over Wi-Fi**: they go with a build only when exporting to a folder or SD. No WebDAV yet.
- Сохранения многодисковых игр не синхронизируются со сборкой. / Saves of multi-disc games don't sync with builds.

Ошибки и идеи / Bugs and ideas: [Issues](https://github.com/wirgylle/AegisROM/issues).
