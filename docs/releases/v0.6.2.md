## AegisROM 0.6.2 (beta)

Версия 0.6.1 не выпускалась: её релиз опубликован без файлов. Всё, что для неё готовилось, вошло в 0.6.2.
Version 0.6.1 was skipped: its release was published without files. Everything planned for it is in 0.6.2.

### Что скачать / Downloads
- `AegisROM-Setup-v0.6.2-Win11-x64.exe`: установщик для Windows, рекомендуется / Windows installer, recommended.
- `AegisROM-Portable-Win11-x64.exe`: портативная версия без установки / portable, no install.
- `AegisROM-v0.6.2-Win11-x64.zip`: всё одним архивом / everything in one archive.
- `aegis-scanner-win11-x64.exe`: консольный сканер / command-line scanner.
- `AegisROM-v0.6.2-macOS-universal.dmg`: **macOS** `beta`, один файл для Intel и Apple Silicon, macOS 11+ / one file for Intel and Apple Silicon, macOS 11+.

Windows: файлы пока не подписаны. Если SmartScreen предупредит, нажмите «Подробнее» → «Выполнить в любом случае».
Windows: files aren't signed yet. If SmartScreen warns, click "More info" → "Run anyway".

macOS: приложение не подписано Apple, поэтому первый запуск будет заблокирован. Как открыть: [docs/macos.md](https://github.com/wirgylle/AegisROM/blob/main/docs/macos.md).
macOS: the app isn't signed by Apple, so the first start is blocked. How to open it: [docs/macos.md](https://github.com/wirgylle/AegisROM/blob/main/docs/macos.md).

### Что нового / What's new
- **Своё окно на Windows по умолчанию**: AegisROM.exe открывается в собственном окне (WebView2). Если окно не запустилось, программа сама откроется в Edge; переключатель есть в Настройках. / **Own window on Windows by default**: AegisROM.exe opens in its own window (WebView2). If it fails, the app falls back to Edge by itself; there is a switch in Settings.
- **WebDAV и сохранения по Wi-Fi**: заливка сборки по WebDAV (HTTP / HTTPS), галочка «Сверять сохранения»: при заливке сохранения сверяются с приставкой, новое побеждает, обе версии остаются в истории. Зеркало больше не затирает сохранение, которое уже есть на приставке. / **WebDAV and saves over Wi-Fi**: upload a build over WebDAV (HTTP / HTTPS); a "Sync saves" option compares saves with the handheld during upload, the newer one wins and both stay in history. Mirroring no longer overwrites a save already on the handheld.
- **Проверка ромов и CHD для R36S**: новый инструмент вверху вкладки «Инструменты». / **ROM check and CHD for R36S**: a new tool at the top of Tools.
- **Медиа**: «Найти медиа в папках» и «Упорядочить медиа» для папок Skraper `media/*`, версии картинок (V1, V2…) с оценкой и выбором основной, кнопка «Мануал». Сборка берёт медиа из тех же источников, что Библиотека. / **Media**: "Find media in folders" and "Tidy media" for Skraper `media/*` folders, image versions (V1, V2…) with a fit score and a default pick, a "Manual" button. Builds take media from the same sources as the Library.
- **Скраппер** честно показывает «найдено» и «записано» и причины промахов. / **Scraper** shows "found" vs "written" and why games were missed.
- **Хаки и патчер**: сжатые xdelta-патчи (LZMA, DJW), патчер без лимита 512 МБ, патчи из `patch/` находятся и для ромов больше 16 МБ. Сканер больше не считает `[h]` и `[t]` битыми дампами. / **Hacks and patcher**: compressed xdelta patches (LZMA, DJW), no 512 MB patcher limit, `patch/` patches are found for ROMs over 16 MB too. The scanner no longer treats `[h]` and `[t]` as bad dumps.
- **Коллекции и серии**: кнопка «В коллекцию или серию» на роме, окно предложений с прокруткой и правкой перед принятием. / **Collections and series**: an "Add to a collection or series" button on a ROM, a suggestions window with scrolling and editing before accepting.
- **Выгрузка сборки**: две линии копирования, таймауты, остановка и продолжение. / **Build export**: two copy lanes, timeouts, stop and resume.
- **Исправлено**: каталог PortMaster снова загружается (ошибка `cannot unmarshal array … attr.avail`). / **Fixed**: the PortMaster catalog loads again (the `cannot unmarshal array … attr.avail` error).

### Beta
Эти функции есть, но ещё в разработке / These work but are still in development:
- версия для macOS / the macOS version;
- заливка и сохранения по Wi-Fi / Wi-Fi upload and saves;
- сохранения / saves;
- запуск во встроенном эмуляторе: не все консоли и форматы / play in the built-in emulator: not every console and format;
- каталог PortMaster и проверка портов на ПК / PortMaster catalog and PC port check.

### Известные проблемы / Known issues
- **macOS на настоящем Mac не проверялась.** / **macOS hasn't been checked on a real Mac.**
- **Заливка и сохранения по Wi-Fi на настоящих приставках не проверялись**, только на тестовых серверах SFTP, SMB и WebDAV. WebDAV не докачивает прерванную заливку. / **Wi-Fi upload and saves haven't been checked on real handhelds**, only against test SFTP, SMB and WebDAV servers. WebDAV doesn't resume an interrupted upload.
- Сохранения в отдельной папке прошивки (muOS, Batocera `saves/`) и сохранения многодисковых игр пока не синхронизируются. / Saves in a firmware's separate folder (muOS, Batocera `saves/`) and saves of multi-disc games don't sync yet.

Ошибки и идеи / Bugs and ideas: [Issues](https://github.com/wirgylle/AegisROM/issues).
