# Скриншоты для README

Положите сюда PNG-файлы с этими именами, и они появятся в главном README:

| Файл | Что снять |
|---|---|
| `library.png` | Вкладка «Библиотека», вид «Витрина» с обложками |
| `tools.png` | Вкладка «Инструменты» |
| `builds.png` | Вкладка «Сборки» |

Рекомендуемая ширина 1600–1920 px, светлая или тёмная тема на выбор.
